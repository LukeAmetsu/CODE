# Engineering Calculator Hub

This project is a web-based collection of engineering calculators designed to provide quick and accurate results for common engineering tasks.

- [Usage](#usage)
- [Project Structure](#project-structure)

## Getting Started

To get a local copy up and running, follow these simple steps:

1. Clone the repo:
   ```sh
   git clone https://github.com/your_username_/your_project_name.git
   ```
2. Open `index.html` in your browser.

## Usage

This project is a static website, so you can use it by simply opening the `index.html` file in your web browser. From there, you can navigate to the various calculators.

## Project Structure

The project is organized into the following directories:

- `aci/`: Contains calculators related to ACI (American Concrete Institute) codes.
- `aisc/`: Contains calculators related to AISC (American Institute of Steel Construction) codes.
- `asce/`: Contains calculators related to ASCE (American Society of Civil Engineers) codes.
- `js/`: Contains the JavaScript code for the calculators.
  - `shared-utils.js`: Contains utility functions shared across all calculators.
- `nbr/`: Contains calculators related to NBR (Brazilian Association of Technical Standards) codes.
- `nds/`: Contains calculators related to NDS (National Design Specification for Wood Construction) codes.
